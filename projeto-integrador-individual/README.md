# Projeto Integrador Individual - SysObiOnline

Este diretório reúne os artefatos do projeto integrador individual do sistema SysObiOnline, estruturados em uma pasta separada para facilitar a entrega e a organização do trabalho.

## Visão geral

O projeto SysObiOnline é uma API back-end desenvolvida em ASP.NET Core para apoiar a disponibilização de questões da Olimpíada Brasileira de Informática (OBI), com autenticação, cadastro de usuários, gestão de questões, geração de relatórios e lógica de quiz.

## Repositório base

- Repositório: `SIUFC/SysObiOnline`
- Arquivo do projeto integrador identificado no repositório: `Projeto Integrador Individual de Gerência de Projetos de Software.pdf`

1. `incremento-1-planejamento-inicial.md` — relatório consolidado do Incremento 1, com objetivos, stakeholders, Business Case, viabilidade, BSC, requisitos, EAP, dependências e estimativa de esforço.
2. `incremento-2-planejamento-e-controle.md` — cronograma PERT/PDM/CPM, custos, valor agregado, qualidade, recursos, comunicação e riscos do Incremento 2.

4. `RELATORIO_PROJETO_INTEGRADOR.txt` — relatório em texto que consolida os três incrementos e orienta os passos de entrega.

## Resumo do projeto

### Objetivo do sistema

- permitir o cadastro e autenticação de usuários;
- disponibilizar questões por nível, ano e fase da OBI;
- registrar respostas e gerar relatórios de desempenho;
- manter a estrutura do sistema em uma API pronta para integrações com frontend.

### Principais módulos

- autenticação e usuários;
- administração de questões;
- processamento de respostas;
- relatórios e estatísticas;
- acesso via JWT e Swagger.

### Tecnologias observadas no repositório

- ASP.NET Core
- Entity Framework Core
- SQL Server
- JWT (autenticação)
- Swagger/OpenAPI
- C#

## Entregáveis propostos

- análise de contexto e objetivos;
- requisitos do sistema;
- arquitetura da solução;
- backlog e cronograma;
- gestão de riscos e mitigação;
- mapa dos endpoints da API.
