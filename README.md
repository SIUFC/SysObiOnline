# SysObiOnline
OBI - Back End

Este é um sistema de questões para alunos da Olimpiada Brasileira de Informática, sistema próprio da Universidade Federal do Ceara. Desenvolvido por @PedroAlvesPro com o objetivo de simplificar o acesso as questões da OBI para alunos que irão prestão a prova.

Para usar o projeto, precisa:
A) Baixar as extensões do projeto, Ef Core, Asp .Net, Sql Server, etc..
B) Ter o SQL Server na máquina - Criar um banco de dados SysObi, de acordo com o /*   "DefaultConnection": "Server=localhost\\SQLEXPRESS;Database=SysObi;Integrated Security=True;TrustServerCertificate=True;" */
Também, ter a autenticação padrao do Windows ou adicionar a autenticação de nome e usuário. Iniciar o serviço de banco de dados e também conectar com o SMSS do Managent. Alterar o DefaultConnection supra citado.
